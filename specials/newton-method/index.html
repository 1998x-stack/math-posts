牛顿迭代法：
用切线寻找方程的根

从一次大胆的直线近似出发，理解一个能让误差不断平方的算法，以及它为何有时会彻底失效。

函数或可靠步骤切线与预测真根或夹根区间

01 · 为什么要找零点？

假如计算器没有平方根键，你能只用加减乘除求出 √2 吗？我们知道它在 1 和 2 之间，但如何从这条粗略信息迅速得到十几位小数？

x2−2=0
(1)

二分法每次取区间中点，利用符号保留含根的一半。它可靠，但只使用了函数的正负号。牛顿法还利用一个额外信息：函数在当前位置的斜率。斜率告诉我们，要消除当前高度，大致需要横向移动多少。

02 · 把曲线暂时当作直线

在当前猜测 xₙ 处，函数值 f(xₙ) 是点 P 的高度，导数 f′(xₙ) 是切线斜率。若斜率非零，切线与横轴有唯一交点。我们用那个交点替代原来的猜测。

根据高中数学的点斜式，切线为：

y=f(xn)+f′(xn)(x−xn)
(2)

令切线高度 y = 0，把未知横坐标记为下一次猜测 xₙ₊₁。移项并除以非零导数，得到：

xn+1=xn−f(xn)f′(xn)
(3)
核心思想：不是直接解一个难解的非线性方程，而是连续求解容易的线性近似。分子表示当前残差，分母表示局部变化率；二者的比值就是预测的横向修正量。

03 · 亲手算出 √2

把 f(x)=x²−2 和 f′(x)=2x 代入公式（xₙ ≠ 0），就会出现一个熟悉的算术平均：

xn+1=xn−xn2−22xn=12(xn+2xn)
(4)

若 xₙ 是一个正的高估值，那么 2/xₙ 就是低估值。取两者的平均，得到更精确的高估值。对任意正初值，第一步起都不小于 √2；之后单调下降并趋向 √2。这来自算术—几何平均不等式及 x > √2 时 2/x < x。

04 · 为什么误差会平方？

切线法为什么比只看符号快？定义真根为 r，误差为 eₙ = xₙ − r。假设 f 在根附近二阶连续可导，f(r)=0 且 f′(r)≠0，即 r 是单根。

对 f(r) 在 xₙ 处做带拉格朗日余项的泰勒展开，其中 ξ 位于 xₙ 与 r 之间：

0=f(xn)+f′(xn)(r−xn)+f″(ξ)2(r−xn)2
(5)

移项，再代入牛顿公式，得到误差恒等式：

en+1=f″(ξ)2f′(xn)en2
(6)

在足够小的邻域内，可找到常数 M ≥ 0 和 m > 0，分别使 |f″| ≤ M、|f′| ≥ m。因此

|en+1|≤M2m|en|2
(7)

若初始误差足够小（例如取 C=M/(2m)>0 时 C|e₀|<1，并令初值位于上述邻域），误差界保证迭代留在邻域并趋于零。这就是至少二次的局部收敛；若 f″(r)≠0，通常具有非零二次误差常数。所谓有效数字近似翻倍，是渐近现象，并非每一步的保证。

平方根例子还可以直接代数化简，无需泰勒定理，得到：

en+1=en22xn
(8)

06 · 牛顿法并不保证成功

反例一：切线水平

令 f(x)=x³−1，从 x₀=0 开始。此时 f(0)=−1、f′(0)=0，切线是水平线，根本没有横轴交点。若导数很小但非零，修正量也可能异常大。

反例二：在两个点之间循环

对 f(x)=x³−2x+2，f′(x)=3x²−2。从 0 出发，下一点是 1；再从 1 出发，下一点却是 0。每一步都有合法切线，但永远到不了真根。

反例三：重根失去二次收敛

对 f(x)=(x−1)²，当 xₙ≠1 时，普通牛顿步化简为：

xn+1=xn−(xn−1)22(xn−1)=xn+12
(9)

误差每步变为上一轮的一半。如果已知根的重数 m（函数在根附近可写成 (x−r)ᵐg(x)，g(r)≠0，且 g 足够光滑），可采用修正牛顿法，恢复至少二次的局部收敛：

xn+1=xn−mf(xn)f′(xn)
(10)

07 · 如何把它变成可靠的算法

先用绘图或区间搜索选初值，检查函数定义域。若存在连续函数的异号区间 [a,b]，可以保留夹根区间并尝试牛顿步。比如只接受落在区间中间一半内的牛顿候选，否则采用中点。更新异号区间时长度至多变为原来的 3/4。

残差阈值需要考虑函数尺度；步长很小也可能只是舍入停滞。在工程中可结合步长、残差、区间宽度、导数阈值及最大迭代次数，并返回明确状态。下面是教学用途的 Python 实现（无第三方依赖）：

def newton(f, df, x, tol=1e-12, max_iter=50):
    from math import isfinite
    for n in range(max_iter + 1):
        y = f(x)
        if not isfinite(y):
            return x, "nonfinite", n
        if abs(y) <= tol:
            return x, "residual tolerance", n
        if n == max_iter:
            break
        d = df(x)
        if not isfinite(d) or abs(d) < 1e-14:
            return x, "unsafe derivative", n
        z = x - y / d
        if not isfinite(z) or z == x:
            return x, "nonfinite or stagnation", n
        x = z
    return x, "iteration limit", max_iter

x, status, n = newton(lambda x: x*x-2,
                      lambda x: 2*x, 2.0)
print(x, status, n)

这段代码是普通牛顿法，并未实现图 8 的夹根保护；配套 Python 文件另附区间保护实现与测试。对于任意自定义函数，还应处理定义域异常和尺度相关的阈值。

08 · 从求根到最优化

如果目标是寻找可微函数 f 的驻点，问题变成求 f′(x)=0。将牛顿法施加于 f′，便得到优化中的牛顿步：

xn+1=xn−f′(xn)f″(xn)
(11)

驻点不一定是最小值：还需要检查曲率及其他条件。多变量求根同样遵循局部线性化：令 F 为 n 维向量值函数，Jₙ 为当前位置的 n×n 雅可比矩阵，求解线性系统：

JnΔxn=−F(xn),xn+1=xn+Δxn
(12)

通常直接解线性系统而不是显式求逆；雅可比矩阵奇异、初值不佳等问题仍然存在。最优化中对应的二阶矩阵是 Hessian，常配合阻尼、线搜索或信赖域。

09 · 回顾与延伸阅读

记住三件事：用切线替代曲线，用交点替代猜测；单根附近的误差受平方量级控制；初值、导数与停止条件决定算法能否可靠工作。

牛顿迭代公式及单根与重根的收敛性质，可参阅 NIST DLMF §3.8(ii), Newton’s Rule；二分法见 §3.8(iii)；多元方程见 §3.8(vii)。本章的平方根计算、反例与误差推导均可独立复算。
