MATHEMATICAL EXPLORATIONS / GEOMETRY

几何变换与不变量：12讲

有时候题目难，不是计算复杂，而是我们还没找到该保持的结构。从反演与螺旋相似，到欧拉线与射影几何：用图形发现关系，再把关系写成可核对的证明。

建议每讲 90—120 分钟。01—04 讲侧重基本变换与比例；05—09 讲练习圆、共圆与有向角；10—12 讲接触交比、极性与射影定理。先完成基础例题，再尝试进阶练习。

三条学习路径

从几何变换出发：01 → 02 → 03 → 07；从圆与共点出发：04 → 05 → 06 → 08 → 09；射影拓展：10 → 11 → 12。

每篇包含可调参数的动态几何图、四个渐进观察状态、关键 MathML 公式、独立推理、易错边界、三道分层练习。图形用于理解；证明必须由定义和定理支持。
