哈达玛行列式不等式法

二维面积如何通过升维变成三个正交向量的体积？

问题与猜想

给定长半轴 a、短半轴 b 的椭圆。在椭圆上任取三个不同的点 A、B、C，求三角形面积的最大值，并刻画全部取等情况。

x 2 a 2 + y 2 b 2 = 1 , a ≥ b > 0
(01)

直觉上，三个点应尽量分散。但如何把“分散”转化为可证明的数学条件？

面积行列式中藏着第三维

归一化顶点为 (uᵢ,vᵢ)，其中 uᵢ²+vᵢ²=1。三角形的两倍面积是一个三阶行列式的绝对值乘以 ab。

S = a b 2 | u 1 v 1 1 u 2 v 2 1 u 3 v 3 1 |
(02)

第三列原本只是为了表达平移不变的面积。现在主动将它解释为高度。

引入可以调节的高度

设 t>0，构造行向量 rᵢ=(uᵢ,vᵢ,t)。将原行列式第三列乘以 t，所以新行列式是原行列式的 t 倍。

M t = ( u 1 v 1 t u 2 v 2 t u 3 v 3 t ) , S = a b 2 t | det M t |
(03)
‖ r i ‖ = 1 + t 2
(04)

三个向量的长度相等，不论顶点如何移动。这是能够使用哈达玛不等式的原因。

为什么正交时体积最大

哈达玛不等式可由 Gram–Schmidt 正交化理解：平行六面体的体积等于第一条棱的长度，乘第二条棱垂直于第一条棱的分量，再乘第三条棱垂直于前两条棱张成平面的分量。每个分量都不超过原棱长度。

| det M t | ≤ ∏ i = 1 3 ‖ r i ‖ = ( 1 + t 2 ) 3 / 2
(05)
S ≤ a b 2 t ( 1 + t 2 ) 3 / 2
(06)

当三个非零行向量两两垂直时取等。

怎样选择最优高度

上界仍含自由设计参数 t。令 F(t)=(1+t²)^(3/2)/t；求导得

F ′ ( t ) = 1 + t 2 ( 2 t 2 − 1 ) t 2
(07)

当 t=1/√2 时，上界最小。此时正交要求

r i ⋅ r j = u i u j + v i v j + 1 2 = 0 ( i ≠ j )
(08)
u i u j + v i v j = − 1 2
(09)

单位圆上存在这样的三个点：参数角间隔 120°。所以优化得到的上界不是虚的，确实能达到。

S max = a b 2 2 ( 3 2 ) 3 / 2 = 3 3 4 a b
(10)

亲手检验：改变参数，观察面积

固定最优三角形，改变辅助高度；观察行向量内积和面积上界如何变化。

结论、边界与自测

最大面积
S max = 3 3 4 a b
(11)

当且仅当三个顶点的位置向量之和为零，即三角形重心与椭圆中心重合。等价地，三个椭圆参数角相隔 120°。

A + B + C = 0
(12)

一个可直接代入验证的取等例：

A = ( a , 0 ) , B = ( − a 2 , 3 b 2 ) , C = ( − a 2 , − 3 b 2 )
(13)

上述结论假设 a、b 均为正；退化椭圆不属于本题。若 a=b，最大三角形是实际的正三角形；若 a≠b，则通常不是。

高度 t 是原椭圆的某个几何高度吗？

不是。它是行列式证明中引入的自由参数；选择它是为了得到最紧的上界。

可运行的数值检查（Python 标准库）

以下计算只检验一个取等构型，不能替代前面的严格证明。

from math import sin, cos, pi, sqrt, isclose

def area(points):
    return abs(sum(x*v-y*u for (x,y),(u,v)
               in zip(points, points[1:]+points[:1])))/2

a, b, theta = 5, 3, 0.37
points = [(a*cos(theta+2*pi*i/3),
           b*sin(theta+2*pi*i/3)) for i in range(3)]
assert isclose(area(points), 3*sqrt(3)*a*b/4)
assert all(abs(sum(p[j] for p in points)) < 1e-12
           for j in range(2))
print(area(points))
