三角变换法

三个角如何合成一个最值？从正弦差到三角函数乘积。

问题与猜想

给定长半轴 a、短半轴 b 的椭圆。在椭圆上任取三个不同的点 A、B、C，求三角形面积的最大值，并刻画全部取等情况。

x 2 a 2 + y 2 b 2 = 1 , a ≥ b > 0
(01)

直觉上，三个点应尽量分散。但如何把“分散”转化为可证明的数学条件？

把顶点写成参数角

按照逆时针顺序选取三个参数角 α、β、γ，使 α<β<γ<α+2π。注意参数角是单位圆上的角，不是椭圆中 OA 与 x 轴之间的实际夹角。

A = ( a cos ⁡ α , b sin ⁡ α ) ,   B = ( a cos ⁡ β , b sin ⁡ β ) ,   C = ( a cos ⁡ γ , b sin ⁡ γ )
(02)
2 S = a b | sin ⁡ ( β − α ) + sin ⁡ ( γ − β ) + sin ⁡ ( α − γ ) |
(03)

面积公式来自三个位置向量的二维行列式之和。即使原点位于三角形外，有向面积仍然正确。

为什么引入半角

令三个相邻参数角差的一半分别为 x、y、z。因为绕行一周，这三个数正好组成一个三角形的内角和。

x = β − α 2 ,   y = γ − β 2 ,   z = 2 π + α − γ 2
(04)
x + y + z = π , x , y , z > 0
(05)
sin ⁡ 2 x + sin ⁡ 2 y = 2 sin ⁡ z cos ⁡ ( x − y )
(06)
sin ⁡ 2 x + sin ⁡ 2 y + sin ⁡ 2 z = 2 sin ⁡ z [ cos ⁡ ( x − y ) − cos ⁡ ( x + y ) ] = 4 sin ⁡ x sin ⁡ y sin ⁡ z
(07)

因三个正弦均为正，绝对值可以去掉。

固定一个角，让另外两个相等

面积化为三个正弦的乘积。固定 z 之后，x+y 不变，而 cos(x−y) 的最大值为 1。

S = 2 a b sin ⁡ x sin ⁡ y sin ⁡ z
(08)
sin ⁡ x sin ⁡ y = cos ⁡ ( x − y ) + cos ⁡ z 2 ≤ 1 + cos ⁡ z 2 = cos 2 ⁡ z 2
(09)

等号当且仅当 x=y，因为 x−y 在 (−π,π) 内。现在只剩 z 一个自由变量。

S ≤ 4 a b sin ⁡ z 2 cos 3 ⁡ z 2
(10)

最后的单变量最值

令 t=sin(z/2)，则 0<t<1。可以使用导数，也可以对平方使用四项均值不等式，完全避免微积分。

S ≤ 4 a b t ( 1 − t 2 ) 3 / 2
(11)
t 2 ( 1 − t 2 ) 3 = 27 t 2 ( 1 − t 2 3 ) 3 ≤ 27 256
(12)
t 2 = 1 − t 2 3 ⟹ t = 1 2
(13)

因此 z=π/3，再结合 x=y 和三角约束，三个半角均为 π/3。

S max = 3 3 4 a b
(14)

亲手检验：改变参数，观察面积

保持 z=60°，让 x 和 y 一增一减；观察乘积如何随不均衡程度下降。

结论、边界与自测

最大面积
S max = 3 3 4 a b
(15)

当且仅当三个顶点的位置向量之和为零，即三角形重心与椭圆中心重合。等价地，三个椭圆参数角相隔 120°。

A + B + C = 0
(16)

一个可直接代入验证的取等例：

A = ( a , 0 ) , B = ( − a 2 , 3 b 2 ) , C = ( − a 2 , − 3 b 2 )
(17)

上述结论假设 a、b 均为正；退化椭圆不属于本题。若 a=b，最大三角形是实际的正三角形；若 a≠b，则通常不是。

固定 z 时，为什么不能直接令三个半角相等？

固定 z 不一定是 π/3，只能先令 x=y；再对 z 求最值，才得到三角相等。

可运行的数值检查（Python 标准库）

以下计算只检验一个取等构型，不能替代前面的严格证明。

from math import sin, cos, pi, sqrt, isclose

def area(points):
    return abs(sum(x*v-y*u for (x,y),(u,v)
               in zip(points, points[1:]+points[:1])))/2

a, b, theta = 5, 3, 0.37
points = [(a*cos(theta+2*pi*i/3),
           b*sin(theta+2*pi*i/3)) for i in range(3)]
assert isclose(area(points), 3*sqrt(3)*a*b/4)
assert all(abs(sum(p[j] for p in points)) < 1e-12
           for j in range(2))
print(area(points))
