直线与韦达定理法

把三个动点变成一条弦：斜率为什么最终消失？

问题与猜想

给定长半轴 a、短半轴 b 的椭圆。在椭圆上任取三个不同的点 A、B、C，求三角形面积的最大值，并刻画全部取等情况。

x 2 a 2 + y 2 b 2 = 1 , a ≥ b > 0
(01)

直觉上，三个点应尽量分散。但如何把“分散”转化为可证明的数学条件？

用直线控制底边

设 AB 所在直线为 y=kx+m。非退化三角形至少有一条非竖直边，故可选这样的 AB，不损失一般性。把直线代入椭圆方程，令 D=b²+a²k²。

D x 2 + 2 a 2 k m x + a 2 ( m 2 − b 2 ) = 0
(02)
D = b 2 + a 2 k 2 > 0 , Δ = 4 a 2 b 2 ( D − m 2 )
(03)

两个不同交点要求 m²<D。用一条直线的两个参数代替底边两端点的四个坐标。

韦达定理求弦长

设交点横坐标为 x₁、x₂。韦达定理直接给出根的和与积，无需求出两个根本身。

x 1 + x 2 = − 2 a 2 k m D , x 1 x 2 = a 2 ( m 2 − b 2 ) D
(04)
| x 1 − x 2 | = ( x 1 + x 2 ) 2 − 4 x 1 x 2 = 2 a b D − m 2 D
(05)

由于 y₁−y₂=k(x₁−x₂)，所以真实弦长为

| A B | = 2 a b 1 + k 2 D − m 2 D
(06)

平行切线给出最大高

固定 AB 后，只需让 C 到底边的距离最大。考虑平行线 y=kx+n，其与椭圆联立所得判别式非负。

4 a 2 b 2 ( D − n 2 ) ≥ 0 ⟹ − D ≤ n ≤ D
(07)
h = | y C − k x C − m | 1 + k 2 ≤ D + | m | 1 + k 2
(08)

当 m>0 时，最远切线为 n=−√D；m<0 时取正号；m=0 时两端均可。这样求的是全椭圆上的最大距离，而非局部近似。

整体换元与取等

将弦长与最大高代入底乘高的一半。两个含斜率的根式相消，令 t=|m|/√D。

S ≤ a b D D − m 2 ( D + | m | ) = a b ( 1 + t ) 1 − t 2
(09)
( 1 − t ) ( 1 + t ) 3 = 27 ( 1 − t ) ( 1 + t 3 ) 3 ≤ 27 16
(10)

等号条件为 t=1/2。若 m>0，则 m=√D/2，使用韦达根和求得弦中点 M，使用判别式为零的重根求得切点 C。

M = ( − a 2 k 2 D , b 2 2 D ) , C = ( a 2 k D , − b 2 D )
(11)

故 C=−2M，A+B+C=0。m<0 时对称成立。

亲手检验：改变参数，观察面积

移动弦的位置，第三个顶点保持在最远平行切线上；旋转参数方向改变弦方向。

结论、边界与自测

最大面积
S max = 3 3 4 a b
(12)

当且仅当三个顶点的位置向量之和为零，即三角形重心与椭圆中心重合。等价地，三个椭圆参数角相隔 120°。

A + B + C = 0
(13)

一个可直接代入验证的取等例：

A = ( a , 0 ) , B = ( − a 2 , 3 b 2 ) , C = ( − a 2 , − 3 b 2 )
(14)

上述结论假设 a、b 均为正；退化椭圆不属于本题。若 a=b，最大三角形是实际的正三角形；若 a≠b，则通常不是。

为什么斜率有限的假设不丢失全局最优？

非退化三角形不可能三条边都是竖直线，任意三角形都可以选择一条非竖直边作底。

可运行的数值检查（Python 标准库）

以下计算只检验一个取等构型，不能替代前面的严格证明。

from math import sin, cos, pi, sqrt, isclose

def area(points):
    return abs(sum(x*v-y*u for (x,y),(u,v)
               in zip(points, points[1:]+points[:1])))/2

a, b, theta = 5, 3, 0.37
points = [(a*cos(theta+2*pi*i/3),
           b*sin(theta+2*pi*i/3)) for i in range(3)]
assert isclose(area(points), 3*sqrt(3)*a*b/4)
assert all(abs(sum(p[j] for p in points)) < 1e-12
           for j in range(2))
print(area(points))
