共轭直径法

在椭圆自身的斜坐标系中，弦中点为什么只需走到半径的一半？

问题与猜想

给定长半轴 a、短半轴 b 的椭圆。在椭圆上任取三个不同的点 A、B、C，求三角形面积的最大值，并刻画全部取等情况。

x 2 a 2 + y 2 b 2 = 1 , a ≥ b > 0
(01)

直觉上，三个点应尽量分散。但如何把“分散”转化为可证明的数学条件？

认识共轭半直径

任取参数角 θ，定义椭圆上的两个位置向量 p、q。

p = ( a cos ⁡ θ , b sin ⁡ θ ) , q = ( − a sin ⁡ θ , b cos ⁡ θ )
(02)
det ( p , q ) = a b ( cos 2 ⁡ θ + sin 2 ⁡ θ ) = a b
(03)

二者一般不垂直，但在带权内积下正交且模长为 1。由切线方程可知 p 点切线平行 q，q 点切线平行 p。它们构成的平行四边形面积恒为 ab。

任何弦都有自然的中点坐标

给定任意弦 AB，选择 q 与弦平行的共轭坐标系。由于 q 的方向随 θ 遍历所有方向，这总能实现。写任一点 X=up+vq，代入椭圆方程得 u²+v²=1。弦上 u 是常数，调整 p 的朝向可令 u=t≥0。

A = t p + 1 − t 2 q , B = t p − 1 − t 2 q
(04)
M = t p , 0 ≤ t < 1
(05)

弦中点总在共轭直径 p 上。这是椭圆的平行弦中点定理的一个直接证明。

最大高不必计算真实垂线

第三个顶点写成 C=up+vq，其中 |u|≤1。由于 AB 平行 q，面积行列式中 C 的 q 分量不贡献面积。

S = 1 2 | det ( B − A , C − M ) | = a b 1 − t 2 | u − t |
(06)

固定 t≥0 时，|u−t| 最大为 1+t；u=−1 对应 C=−p。若 t=0，另一端 p 也可取等。注意 MC 通常不是高，但使用行列式仍然完全正确。

S ≤ a b ( 1 + t ) 1 − t 2
(07)

最佳弦中点是半径中点

平方后利用均值不等式，或直接求导。

[ ( 1 + t ) 1 − t 2 ] 2 = ( 1 − t ) ( 1 + t ) 3 ≤ 27 ( ( 1 − t ) + ( 1 + t ) 4 ) 4 = 27 16
(08)

等号需 1−t=(1+t)/3，即 t=1/2。此时 M=p/2，C=−p，故 C+2M=0。

S max = 3 3 4 a b , C O = 2 O M
(09)

几何意义：椭圆中心将中线按重心的 2:1 比例分割。方向任意，因此最大三角形有一整族。

亲手检验：改变参数，观察面积

沿共轭直径移动弦中点，检查 t=1/2 时的重心关系；旋转方向验证面积不变量。

结论、边界与自测

最大面积
S max = 3 3 4 a b
(10)

当且仅当三个顶点的位置向量之和为零，即三角形重心与椭圆中心重合。等价地，三个椭圆参数角相隔 120°。

A + B + C = 0
(11)

一个可直接代入验证的取等例：

A = ( a , 0 ) , B = ( − a 2 , 3 b 2 ) , C = ( − a 2 , − 3 b 2 )
(12)

上述结论假设 a、b 均为正；退化椭圆不属于本题。若 a=b，最大三角形是实际的正三角形；若 a≠b，则通常不是。

为什么不能直接用 AB×MC/2 算面积？

MC 通常与 AB 不垂直，必须用行列式或乘夹角正弦；共轭不等于欧氏垂直。

可运行的数值检查（Python 标准库）

以下计算只检验一个取等构型，不能替代前面的严格证明。

from math import sin, cos, pi, sqrt, isclose

def area(points):
    return abs(sum(x*v-y*u for (x,y),(u,v)
               in zip(points, points[1:]+points[:1])))/2

a, b, theta = 5, 3, 0.37
points = [(a*cos(theta+2*pi*i/3),
           b*sin(theta+2*pi*i/3)) for i in range(3)]
assert isclose(area(points), 3*sqrt(3)*a*b/4)
assert all(abs(sum(p[j] for p in points)) < 1e-12
           for j in range(2))
print(area(points))
