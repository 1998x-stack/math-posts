椭圆内接三角形 · 01 / 07

仿射变换法

把椭圆拉回圆：形状变了，面积的排序为什么不变？

问题与猜想

给定长半轴 a、短半轴 b 的椭圆。在椭圆上任取三个不同的点 A、B、C，求三角形面积的最大值，并刻画全部取等情况。

x 2 a 2 + y 2 b 2 = 1 , a ≥ b > 0
(01)

直觉上，三个点应尽量分散。但如何把“分散”转化为可证明的数学条件？

从三个动点到一个圆

直接对三个椭圆顶点求面积，会出现六个坐标和三个约束。真正困难的不是面积公式，而是横纵尺度不一样。将横坐标除以 a、纵坐标除以 b 后，所有点都满足单位圆方程。

T ( u , v ) = ( a u , b v ) , u = x a , v = y b
(02)
x 2 a 2 + y 2 b 2 = u 2 + v 2 = 1
(03)

这是一个双射：每个椭圆三角形都来自唯一的圆三角形，反过来也成立。所以没有漏掉任何候选。

为什么面积只乘一个常数

记圆上的对应顶点为 A′、B′、C′。任意两条边向量经过矩阵 M 作用后，平行四边形面积乘以行列式的绝对值；三角形是它的一半。

M = ( a 0 0 b ) , det M = a b
(04)
S = 1 2 | det ( M ( B ′ − A ′ ) , M ( C ′ − A ′ ) ) | = a b S ′
(05)

关键是 ab 对所有三角形都相同，因而面积的大小排序不变。不能将这个结论误用到边长、周长或实际角度上。

圆上为什么是正三角形

设圆上三个单位位置向量为 u、v、w，三边长分别为 p、q、r。展开三个平方距离，得到一个与重心有关的恒等式。

p 2 + q 2 + r 2 = 9 − ‖ u + v + w ‖ 2 ≤ 9
(06)
p q r ≤ ( p 2 + q 2 + r 2 3 ) 3 / 2 ≤ 3 3
(07)

外接圆半径为 1，利用正弦定理及面积公式 S′=pqr/(4R)，即得上界。等号需要三个边长相同，且三个位置向量和为零；单位圆的正三角形确实满足。

S ′ ≤ 3 3 4
(08)

从圆变回椭圆

将任意方向的圆内接正三角形伸缩回椭圆。它的三个参数角相隔 120°。线性映射保持向量和，因此重心仍在原点。

A + B + C = M ( A ′ + B ′ + C ′ ) = 0
(09)
S max = a b ⋅ 3 3 4
(10)

逆向也成立：三个单位向量和为零时，由 u+v=−w 得 u·v=−1/2，同理其他两对，因此对应圆三角形一定是正三角形。

亲手检验：改变参数，观察面积

改变纵向伸缩，检查面积缩放因子；此处固定圆上的正三角形，a=5。

结论、边界与自测

最大面积
S max = 3 3 4 a b
(11)

当且仅当三个顶点的位置向量之和为零，即三角形重心与椭圆中心重合。等价地，三个椭圆参数角相隔 120°。

A + B + C = 0
(12)

一个可直接代入验证的取等例：

A = ( a , 0 ) , B = ( − a 2 , 3 b 2 ) , C = ( − a 2 , − 3 b 2 )
(13)

上述结论假设 a、b 均为正；退化椭圆不属于本题。若 a=b，最大三角形是实际的正三角形；若 a≠b，则通常不是。

仿射变换为什么能保最大值，却不能保周长？

因为所有三角形的面积统一乘以 ab，而各方向边长的缩放比例不同。

可运行的数值检查（Python 标准库）

以下计算只检验一个取等构型，不能替代前面的严格证明。

from math import sin, cos, pi, sqrt, isclose

def area(points):
    return abs(sum(x*v-y*u for (x,y),(u,v)
               in zip(points, points[1:]+points[:1])))/2

a, b, theta = 5, 3, 0.37
points = [(a*cos(theta+2*pi*i/3),
           b*sin(theta+2*pi*i/3)) for i in range(3)]
assert isclose(area(points), 3*sqrt(3)*a*b/4)
assert all(abs(sum(p[j] for p in points)) < 1e-12
           for j in range(2))
print(area(points))
