有限差分与数列求和

把离散数列中的相邻差值，变成求和的利器。

难度：提高建议 90—120 分钟差分 · 望远镜求和 · 多项式

01 · 从问题走进结构

你能不用蛮力计算吗？为什么平方数的相邻差是奇数？知道差分后，怎样从一个立方差恒等式求出前 n 个平方数的和？

连续函数用导数研究变化率；数列可以用相邻差描述离散变化。多项式次数每做一次差分便降低一级。

求和常常是差分的逆过程：先找一个高一次的表达式，再利用相邻项连续抵消。

关键转念：先求具体的差分规律，随后挑选一个差值恰好包含目标平方项的立方差。

02 · 改变参数，观察真正的不变量

n=3；aₙ=9；Δaₙ=7；Δ²aₙ=2

四个渐进观察状态

这些观察是探索和数值复核，不是一般性证明。读完图像，应回到下方的条件、代数恒等式与推理链。

03 · 精确定义与核心结论

定义前向差分 Δa_n=a_{n+1}−a_n。对于 n 的 d 次多项式数列，第 d 次差分是常数；若最高项系数为 c，这个常数是 c·d!。求和可通过对差分作望远镜求和实现。

Δan=an+1−an
(01)
Δn2=2n+1；Δ2n2=2
(02)
∑k=1nk2=n(n+1)(2n+1)6
(03)
条件不可省略：高阶差分为常数的结论需要事先知道数列是有次数上界的多项式数列。有限几个样本呈现相同差分不能单独证明所有后续项具有相同结构。

04 · 一道典型例题的完整证明

原课程例题利用立方差和望远镜求和，推导从 1 到 n 的平方和。
∑k=1nk2
(11)

平方数的差分是一次式，因此寻找一个次数更高的多项式差值，将它与平方项联系起来。

1. 建立立方差恒等式

做什么：将相邻整数的立方相减。

为什么：展开后出现目标平方项以及容易求和的一次项。

(k+1)3−k3=3k2+3k+1
(04)

独立检查：一次项系数是三，常数是一。

2. 对两侧从一求和到 n

做什么：同时对两边累加。

为什么：左边每项的负立方会抵消下一项的正立方。

∑k=1n(k+1)3−k3=(n+1)3−1
(05)

独立检查：求和起始是 k=1，因此首个被减去的立方是 1。

3. 用等差数列求和替代一次项

做什么：将立方差右边整理成平方和与一次和。

为什么：前 n 个正整数求和有已知闭式。

∑k=1nk=n(n+1)2
(06)

独立检查：常数项一累加 n 次，得到 n，不是 1。

4. 解出平方和

做什么：把所有非平方和项移到等式右边并因式分解。

为什么：这给出适用于任意正整数 n 的闭式，而不是只满足前几个样本。

∑k=1nk2=n(n+1)(2n+1)6
(07)

独立检查：n=1 时得到一，n=2 时得到五；边界与样例吻合。

带走的方法：找到合适的相邻差值，可以将看似困难的求和变成两端项的简单差。

05 · 适用边界与常见错误

  • 只看前四项的二阶差分相同，就断言任意未来项也符合。
  • 望远镜求和遗漏首项或末项。
  • 将差分算子当作连续导数，忘记它作用于离散下标。

差分算法对多项式非常有效，但对一般数列未必会在有限阶变为零；需要清楚识别适用对象。

06 · 分层练习与答案提示

先完成书面推理，再展开提示；对于有式子的题干，数学关系直接以 MathML 呈现。

基础：推导前 n 个奇数的和。

展开提示与答案

将相邻平方相减得到第 n 个奇数，从一累加即为 n²。

∑k=1n(2k−1)=n2
(08)

巩固：计算 1²+2²+3²+4²，检查平方和公式。

展开提示与答案

直接相加为 30；公式代 n=4 也得到 30。

1+4+9+16=30
(09)

挑战：使用相邻四次方之差探索立方和公式。

展开提示与答案

先将 (k+1)^4−k^4 展开，再用已经求出的低阶求和公式整理，最终得到前 n 个立方和是前 n 个整数和的平方。

∑k=1nk3=n(n+1)22
