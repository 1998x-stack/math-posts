单位根与离散筛选

围绕单位圆的一组复数，为什么高次幂和会突然变成零？

难度：提高建议 90—120 分钟单位圆 · 旋转对称 · 等比级数

01 · 从问题走进结构

你能不用蛮力计算吗？把全部 n 次单位根升到同一个整数次幂，再相加：为什么答案只有两种可能？

单位根是重复固定角度旋转后回到 1 的复数。n 个根等间距分布在单位圆上，排列成正多边形。

当所有根升到 m 次幂时，要先判断旋转是否退化成恒等；这是理解求和为何为零或为 n 的关键。

关键转念：先判断公比是否等于一，再使用有限等比数列求和；分母为零时要单独计数。

03 · 精确定义与核心结论

设 n≥2，取本原 n 次单位根 ω。把 ω 的零次到 n−1 次幂全部相加：其 m 次幂和在 n 整除 m 时等于 n，否则等于 0。

ω=e2πin，ωn=1
(01)
∑k=0n−1ωkm={0n∤mnn∣m
(02)
条件不可省略：n≥2 且 m 为整数；要求 ω 是本原 n 次根，且确实取遍全部 n 项。分母为零的等比级数必须分情况。

04 · 一道典型例题的完整证明

原课程例题（拆分拓展）取四次单位根 1、i、−1、−i，求它们的二次幂和与四次幂和。
{1,i,−1,−i}
(08)

在这个简单案例中可直接逐项计算，但方法应当能延伸到任意 n 和任意 m。

1. 列出完整四次单位根

做什么：令 ω=i，写出前四个幂。

为什么：虚数单位的四次幂是 1，且前四项互异。

i4=1
(03)

独立检查：不要只取 1、−1 两个实根。

2. 检查平方和

做什么：每一项升到二次幂。

为什么：平方结果为 1、−1、1、−1，全部抵消。

1−1+1−1=0
(04)

独立检查：四不整除二，与一般公式相符。

3. 检查四次幂和

做什么：每项升到四次幂。

为什么：四个根的四次幂都是 1，因此总和为 4。

1+1+1+1=4
(05)

独立检查：四整除四，结果处于筛选公式另一分支。

4. 从案例走到一般证明

做什么：设公比 q=ω^m，分别处理 q=1 和 q≠1。

为什么：公比不为一时，将有限幂和乘以 1−q，可消去中间项，最终剩下 1−q^n=0。

(1−q)∑k=0n−1qk=1−qn
(06)

独立检查：当 q=1 时绝不除以 1−q；这时直接数出 n 项。

带走的方法：单位根求和先检查指数与根数的整除关系；复杂复数和因此变成零或整数。

05 · 适用边界与常见错误

  • 角间隔应为 2π/n，不是 π/n。
  • 不能在 q=1 时除以 1−q。
  • 非本原的根可能重复，不能当成互异 n 次根。

对于 n=1，可单独规定唯一单位根为 1；本文聚焦 n≥2 的旋转结构。

挑战：为什么仅取全部 n 次根的一半，不能使用同一个筛选结论？

展开提示与答案

完整几何级数的相消需要所有 n 个根；删去任意一部分会破坏完整周期。
