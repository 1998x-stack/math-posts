# PDF → 数学题转写规范

1. 列出 PDF 总页数、试卷题型与题号，剔除广告页；每道题记录开始/结束页。
2. 先渲染（不只调用纯文字提取），再逐题读取。向量箭头、分式、根号、上下标、图形标签、分段条件、正负号优先按渲染页面核对；必要时裁剪放大。
3. **原题**：不遗漏填空横线、选项 A/B/C/D、大题各小问；不得把解析中更简洁的已知式替换成原始题设。
4. **原解**：记录官方答案和核心推理链；数学错误或笔误需分“原卷文字”和“独立更正”，不能悄悄篡改。
5. 使用数学真值表核查：定义域、等号条件、边界、参数范围、极限、单位、分段函数。适用时写确定性的数值断言。
6. 对无法可靠读取的表达式，状态设为 `draft` 并提供 `uncertainty` 说明；绝不能生成猜测答案后发布。
7. 元数据：`question_number`, `question_type`, `source_pages`; evidence.json 包括 `source`, `transcription`, `answer`。原 PDF 用户上传，不要编造下载 URL。

首批试卷：《2021 年上海市建平中学高考冲刺模拟试卷 3（解析版）》，共 21 道：1–12 填空、13–16 选择、17–21 解答。第 26 页为广告。
