# 数学题型与可视化图解设计手册（Reference v1）

每题从**真实数学对象和学生的疑问**选图，不从 SVG 模板选图。图表的目的必须可以用一句话说清：“学生看到这张图后，能理解为什么……”。

## 0. 共用图形制作合同

- **图形声明**：绘图前写 `visual_assertions`：对象的定义、坐标/长度/角度/取值范围、哪些性质精确、哪些只是示意。
- **几何坐标**：使用同一个数据模型生成点、线、交点、标注和校验值；SVG 显示坐标变换不改变数学定义。
- **区分数学精确与示意**：位置不按比例时明确“示意图，不按比例”；不得示意图画出与条件冲突的关系。
- **可读性**：`viewBox`、`title`、`desc`、对象图例、文本图注；移动端字号与线条可识别；颜色辅以形状/线型。
- **交互**：仅当变量确实影响数学对象时允许滑块/拖动，注明定义域、步长、奇异点、重置值；动画由 `prefers-reduced-motion` 禁用。
- **校验**：图中点坐标、函数值、切线斜率、统计量、极值和面积等与推导一致；渲染不可用时静态图+完整证明仍成立。
- **禁止**：为了封面而重复无关装饰曲线；用有限样本声称证明全域；把三维问题投影图中无法看见的性质说成已证明。

## 1. 题型 → 典型学生疑问 → 推荐图形 → 校验断言

| 题型 | 典型疑问 | 首选图解/互动 | 必须检查的断言 |
|---|---|---|---|
| 集合/区间 | 交并补与端点为何变？ | 数轴、端点空心/实心、集合叠层 | 端点是否取到；并、交运算与区间一致 |
| 一元/分式不等式 | 什么时候需要反转方向？ | 符号表 + 数轴 + 零点/不可取点 | 因子零点、分母禁点、符号正负区间 |
| 函数定义域/值域 | 输入输出对应范围是什么？ | 输入轴→函数映射→输出轴 + 图像 | 定义域、像集、极值取等、空缺点 |
| 函数单调/奇偶/周期 | 图像为何能被折叠或平移？ | 关键区间着色、对称轴/原点、平移叠层 | 对称关系、周期长度、定义域对应 |
| 导数/切线 | 导数符号为什么决定趋势？ | 函数曲线+切线+导函数符号带 | 切点代入、斜率、增减区间、驻点 |
| 导数零点/参数 | 参数变化如何改变根的数目？ | 参数族曲线 + 水平线/切点/临界值 | 根数在阈值变化、重根、取等、定义域 |
| 三角函数 | sin/cos 从哪里来？ | 单位圆与波形同步高亮 | 角度、弧度、象限符号、周期相位 |
| 数列/递推 | 为什么第 n 项会这样变化？ | 离散点、递推箭头、前 n 项和/积趋势 | 只画问题要求的量，n 为正整数，索引不偏移 |
| 组合计数/排列 | 方案为何不重不漏？ | 决策树、分类表、格点计数 | 互斥/穷尽、重复计数、首位限制 |
| 二项式/多项式 | 某项系数怎么找到？ | Pascal 三角形、指数预算/选取格 | 通项指数和、系数、合法整数指标 |
| 概率/条件概率 | 分母样本空间为何改变？ | 事件 Venn 图、样本树、概率面积 | 事件交集、条件样本空间与总和 1 |
| 数据统计 | 均值/方差改变代表什么？ | 原始散点、均值线、箱线图/分布 | 样本大小、权重、单位、离群点 |
| 复数/复平面 | 乘以 i 为何旋转？ | 复平面向量、旋转、模和辐角 | 实虚部、辐角方向、模长与复数运算 |
| 平面向量 | 点积与投影有何关系？ | 两向量、夹角弧、垂足、投影长度 | 正负投影、向量坐标、投影方向 |
| 直线与圆 | 切线与交点在哪里？ | 坐标系、半径垂足、交点运动 | 点到线距离、判别式、切点唯一性 |
| 椭圆/双曲线/抛物线 | 焦点、弦、轨迹为何成立？ | 焦点、准线、动点、轨迹与斜率 | 定义量、离心率、参数范围、退化/竖线 |
| 空间几何 | 看不见的垂直与二面角如何理解？ | 轻量可旋转 3D + 3 个静态投影视图 | 点线面位置、法向量、量角、退化状态 |
| 最值/优化 | 极值为什么在边界或驻点？ | 可行域热区、等值线、最近点/切线 | 可行性、边界/内部候选、开闭性 |
| 应用建模 | 文字条件如何变成公式？ | 变量关系流程图、单位表、约束域 | 每个箭头对应真实条件、单位一致 |
| 逻辑与证明 | 为什么这个条件足够？ | 命题流程图/反例状态机 | 必要/充分方向、反例真实可行 |

上表并非强制每题有动态图：静态 SVG 可清楚表达时应优先使用；“没有有效图解”可以使用符号表、计算表或逐步变形对照图，不能强行画没有数学含义的坐标系。

## 2. 具体图解 Blueprint

### A. 数轴与集合

1. 先画全域/问题范围，单独标出禁点。
2. 使用不同的线型表示原始条件、每个因子的符号、最终可行集。
3. 开区间的空心端点与闭区间实心端点必须与 MathML 区间符号一致。
4. 可测试断言：某开区间不包含端点，某分母为零的点永远不进入解集。

### B. 函数图像与导数

1. 写函数 `f(x)`、定义域、绘图区间与采样方法；在定义域断点处分段绘制。
2. 若显示切线，在 `x=a` 画过 `(a,f(a))`、斜率为 `f'(a)` 的直线。
3. 在 `f'(x)=0` 位置画驻点，向下/向上箭头对应一阶导符号，不把所有驻点称极值。
4. 参数 `a` 改变后，曲线、交点个数、符号表与当前结论同步刷新；特殊值可能导致相切或无解。
5. 断言：在阈值两侧独立算根数；函数图不能替代证明根的存在与唯一性。

### C. 解析几何中的向量与圆锥曲线

1. 先画真实坐标轴、焦点/准线、对象方程和原始可行范围；标注原点与单位。
2. 向量端点和箭头严格来自向量坐标；数量积同时显示夹角与投影，避免用“看着垂直”证明。
3. 动点保持在曲线上，弦的端点满足方程；水平/竖直等特殊斜率应单独处理，**不能预设所有直线存在有限斜率**。
4. “定值/定点”实验至少测试不同合法位置及临界情况；由代数证明给出全称结论。
5. 若原卷条件不足产生反例，展示一组满足原题但违背结论的合法参数；不能暗加排除条件。

### D. 数列、计数与概率

1. 序列使用离散整数索引；显示 `a_n`、`S_n` 或前 `n` 项积中的**实际目标量**，不得误画为其他量。
2. 组合决策树对每条叶路径设唯一方案 ID，展示分类是否重叠与是否完备。
3. 概率树的每层条件概率相加为 1；条件概率更新样本空间，避免将面积示意误当精确数据。

### E. 立体几何

1. 首先提供不依赖 WebGL 的清晰静态图；若需要理解异面直线、法向量、空间角，再升级 Three.js。
2. 交互仅操作真实构型、相机或可调参数；显示“正投影 / 空间视图 / 侧视图”的切换，而非无用途滑杆。
3. 不把屏幕投影的角度当空间角；标注真实三维向量及其计算值。
4. 测试 WebGL 关闭、CDN 失败、触屏旋转、键盘、低动效、无网静态 fallback。

## 3. 静态 SVG 文件的最小语义模板

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 720 360" role="img" aria-labelledby="fig-title fig-desc">
  <title id="fig-title">本题可行域与取等点</title>
  <desc id="fig-desc">直线 x+y=4，阴影为满足约束的区域；点 (2,2) 是距原点最近的可行点。</desc>
  <!-- 真实数据驱动的图元与标注应在此绘制 -->
</svg>
```

静态图中数学公式如果包含不等号，在 XML 属性中必须正确转义；图中的普通 `text` 标签不等于正文的 MathML。必须提供正文的数学表达式和无图阅读可理解的说明。

## 4. 图形质量验收矩阵

- **对象**：所有标识点、线、面、函数都能在题干或步骤中找到对应引用。
- **一致性**：数学公式、图注、实际几何坐标、答案数值与脚本断言一致。
- **状态**：初始、边界、退化、无解与极值状态不产生 NaN/Infinity。
- **互动**：控件步长与合法域一致，焦点与滑动可用，状态变化可观察且可重置。
- **性能**：首屏静态可读，SVG DOM 不重复生成大量无意义元素。
- **教学**：读者看完图能回答本题一个具体的“为什么”，而不是只觉得好看。
