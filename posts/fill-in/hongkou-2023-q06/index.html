无穷等比数列求和：首项 2、公比 1/3 为什么总和是 3

每次保留上一项的三分之一，无穷多项累积为有限的总和 3。

2022.12 · 原题 PDF 第 1 页 · 参考答案第 7 页 · 4 分

01 · 题意拆解：无穷多个数如何求和

题目给定首项为 2、公比为 1/3 的等比数列，要计算“所有项”的和。这里不是要求一个固定 n 的前 n 项和，而是计算当 n 无限增长时部分和的极限。由于公比绝对值小于 1，各项虽然始终为正，却会以固定比例缩小。解题关键在于先建立有限项求和公式，再判断无穷级数是否收敛。

研究对象

等比数列的无穷项和

已知条件

b₁=2，q=1/3

要求什么

无穷级数的极限值

解题路线：通项 → 有限项求和 → 收敛判定 → 求极限并验算。

02 · 原题

已知首项为 2 的等比数列 {bn} 的公比为 13，则这个数列所有项的和为 ______。

已对照上传 PDF 第 1 页题干和第 7 页官方参考答案表。原卷未提供本题完整解析，以下是独立整理的数学推导。

03 · 关键观察

每增加一项，新增量只有上一次的三分之一。前 n 项和 Sₙ 因此持续增加，却始终留有一个正的“尾巴”3−Sₙ。这个尾巴可以精确写成 3(1/3)ⁿ，并随着 n 增大趋近 0。

04 · 一步一步求出总和

  1. 步骤一：求出通项

    等比数列的第 n 项等于首项 2 乘公比的 n−1 次方，这里 n 从 1 开始。

    bn=2(13)n−1

    为什么／检查：n=1 时指数为 0，立刻还原首项 2；n=2 时为 2/3，恰好再乘一次公比。

  2. 步骤二：先求有限前 n 项和

    设 Sₙ=b₁+⋯+bₙ。将 Sₙ 乘以公比 1/3 后与原式相减，中间项全部消去，得到等比数列前 n 项和公式。

    Sn=2(1−(13)n)1−13=3(1−(13)n)

    为什么／检查：这是任意正整数 n 的有限求和恒等式，尚未把 n 当作无穷；由于 (1/3)ⁿ>0，故总有 Sₙ<3。

  3. 步骤三：给“所有项的和”严格定义

    由于公比的绝对值 1/3 小于 1，其 n 次幂随着 n→∞ 逼近 0。所有项的和就是前 n 项和的极限。

    limn→∞Sn=3(1−0)=3

    为什么／检查：关键收敛条件是 |q|<1。如果公比绝对值不小于 1，便不能使用无穷等比求和公式。

  4. 步骤四：利用余项解释“无限逼近”

    前 1、2、3 项的和分别为 2、8/3、26/9。它们都小于 3，但与 3 的差不断缩小。

    3−Sn=3(13)n>0

    为什么／检查：任何有限的 Sₙ 都没有达到 3；3 是无限项和的极限，不能误认为只取前几项相加。

05 · 图解：项变小、部分和逼近 3

06 · 官方答案与独立核验

原卷参考答案：3。

独立核验：S₁=2、S₂=8/3、S₃=26/9 且 3−Sₙ=3/3ⁿ→0，因此极限确实为 3。

易错点：错写成 2/(1+1/3)、忽略 |q|<1 收敛条件，或者以为只算前三项就是无限和。

07 · 方法迁移

首项 a₁、公比 q 的无穷等比级数，只有在 |q|<1 时才有总和 a₁/(1−q)。当 q=1 时部分和持续增加；当 q=−1 时在两个值之间振荡，两种情况都不能将有限求和公式机械延伸为无穷和。
