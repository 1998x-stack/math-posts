填空题 · 第 12 题

抛物线与瞬时速度：关联点的运动有多快

从 x²=3y 隐式求导，到 C 点速率 √3v/20。

上海市嘉定区 2023 届高三一模 · PDF 第 1 页

01 · 题意拆解

A 点沿 y 轴以恒速 v 上升，B 和 C 并不是独立运动：B 在同一高度的抛物线上，C 则是 B 的水平坐标落到 x 轴后的对应点。因而只要写出 C 的横坐标如何随 A 的高度变化，就能通过导数求到达指定高度那一瞬间的速率。

解题路线：A 的高度 y(t) → 抛物线横坐标 x(t) → 链式法则 → 代入 y=100。

02 · 原题

已知抛物线 x²=3y，动点 A 自原点出发，沿 y 轴正方向向上匀速运动，速度大小为 v。过 A 作 y 轴的垂线交抛物线于 B，再过 B 作 x 轴的垂线交 x 轴于 C。当 A 运动至 (0,100) 时，求 C 的瞬时速度大小。

03 · 关键观察

C 的 y 坐标恒为 0，但 x 坐标会变化；两个左右对称支的速度方向相反，速率相同。

04 · 逐步推导

  1. 建立时间参数

    设运动时间 t≥0，则 A=(0,vt)。若取抛物线右支，则 B=(√(3vt),vt)，C=(√(3vt),0)。

    为什么：两次垂线意味着 B 与 A 等高，C 与 B 等横坐标；取左支只会改变速度方向。

  2. 求横向瞬时速度

    由 x²=3y 对 t 求导：2x·dx/dt=3·dy/dt=3v，因此 dx/dt=3v/(2x)。

    为什么：从隐式关系求导可避免在 t=0 处直接误用平方根导数；目标高度为 100，此时 x≠0。

  3. 代入指定位置

    当 y=100 时，|x|=√300=10√3，故 |dx/dt|=3v/(20√3)=√3v/20。

    为什么：瞬时速率是导数绝对值；右支和左支得相同非负数。

05 · 与题设对应的可视化

06 · 答案与独立核验

答案：√3·v / 20

x=10√3 时 2x(dx/dt)=3v；解得 √3v/20，与原卷答案一致。

易错点：不要把 C 沿 x 轴的速度当作 A 的 v；也不要在左右两支之间把有向速度和速率混淆。

07 · 方法迁移

若 x²=ky 且 y'=v，则在 y=h>0 时横向速率为 √k v/(2√h)。
