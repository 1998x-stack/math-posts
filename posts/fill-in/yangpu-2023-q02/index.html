填空题 · 第 2 题 · combinatorics

集合交集：区间 [0,2] 与条件 x ≤ 1 的重合部分

先把集合 B 的条件改写成区间，再在数轴上取共同部分，两个端点都要保留。

上海市杨浦区 2023 届高三一模数学试卷 · 原题 PDF 第 1 页 · 参考答案 PDF 第 8 页

01 · 先理解题目在问什么

题目用两种方式描述集合：A 直接给出 x 的范围，B 则给出一个不等式。求 A∩B，就是找出同时满足这两个条件的所有实数。关键是先把 B 化成区间，再比较端点并判断端点是否包含。

研究对象

两个实数集合 A、B

已知条件

A 中元素满足 0 ≤ x ≤ 2；B 中元素满足 x−1 ≤ 0

求解目标

写出同时属于 A 和 B 的元素范围

解题路线：A=[0,2] → 解出 B 的条件 x≤1 → 取两个区间的交集 → 检查端点开闭。

02 · 原题

设集合 A={x|0≤x≤2}，集合 B={x|x−1≤0}，则 A∩B = ______。

03 · 关键观察

交集不是把两个区间的端点简单拼接，而是保留同时满足两组条件的 x。把每个集合画在同一条数轴上，只留下两条表示范围重叠的部分。

04 · 逐步推导

  1. 先把集合 A 写成区间。 由 0≤x≤2 可知，A=[0,2]。两个不等号都含等号，所以 0 和 2 都属于 A。

    为什么这样做：先记录端点是否包含，后面才能正确决定交集使用圆括号还是方括号。

  2. 把集合 B 的不等式解出来。 x−1≤0，两边同时加 1，得到 x≤1。因此 B=(−∞,1]。

    为什么这样做：移项没有改变不等号方向；B 向左无限延伸，并且包含端点 1。

  3. 取两个范围的共同部分。 A 要求 x≥0 且 x≤2，B 要求 x≤1。合并后得到 0≤x≤1，所以 A∩B=[0,1]。

    为什么这样做：共同部分的左端点取较大的下界 0，右端点取较小的上界 1；两处都来自原题的非严格不等式，因此都包含。

关键数学关系

A=[0,2],B=(−∞,1]
A∩B=[0,2]∩(−∞,1]=[0,1]

06 · 答案与核验

原卷参考答案：[0,1]。

独立核验：若 x∈[0,1]，则 0≤x≤2 且 x−1≤0，所以 x 同时属于 A、B；反过来，若 x 同时属于 A、B，则 0≤x≤2 且 x≤1，合并即 0≤x≤1。

易错点：B 的条件是 x−1≤0，即 x≤1，不是 x≥1；另外，≤ 表示端点包含，交集应写成闭区间 [0,1]。

07 · 方法迁移

两个区间求交时，可以把所有下界取较大的一个、所有上界取较小的一个，再检查边界是否允许取等。如果最终下界大于上界，交集就是空集。
