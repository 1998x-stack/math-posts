上海虹口一模 · 填空题第 7 题

导数与切线方程：在 y=ln x+2x 上寻找斜率为 3 的切线

斜率先定导数，导数再定切点，最后用点斜式确定切线。

2022.12 · 题干 PDF 第 1 页 · 参考答案 PDF 第 7 页 · 5 分

01 · 先看题目在问什么

题目给出了曲线的表达式，却没有告诉切点，只要求切线的斜率等于 3。导数给出每个位置的切线斜率，所以要先在定义域内解 y′(x)=3，找到满足条件的横坐标；然后代回原函数找纵坐标，最后写切线方程。此题的真正难点，是不要把“斜率为 3”错认为“切点纵坐标为 3”。

研究对象

y=lnx+2x 的切线

已知

切线斜率为 3

目标

直线 l 的完整方程

解题路线：定义域 → 求导 → y′=3 → 切点 → 点斜式 → 凹凸性核验。

02 · 原题

设曲线 y=lnx+2x 的斜率为 3 的切线为 l，则 l 的方程为 ______。

原题位于用户上传 PDF 第1页；第7页的参考答案只有结果。以下详解为独立推导，不冒充原卷的官方解题过程。

03 · 关键观察

导数是 1/x+2。x 靠近 0 的正侧时斜率很大；随着 x 增大，斜率逐渐减小并接近 2。斜率等于 3 的位置必然只有一个，因此找到 x=1 就能唯一确定切点。

04 · 逐步推导

  1. 步骤1：对函数求导

    自然对数要求 x>0，分别用 (lnx)′=1/x 和 (2x)′=2 求导相加。

    y′=1x+2

    为什么／检查：不能把 x≤0 当成合法切点，尤其 x=0 不是对数函数定义域中的点。

  2. 步骤2：让导数等于指定的斜率

    切线斜率是切点处的瞬时变化率，因此令 1/x+2=3，求得 x=1。

    1x+2=3⇒x=1

    为什么／检查：在正半轴上 1/x 严格递减，所以解 x=1 唯一；无需额外寻找同斜率的切线。

  3. 步骤3：将横坐标带回原函数

    把 x=1 代入 y=lnx+2x，因 ln1=0，得 y=2。

    y=ln1+2×1=2

    为什么／检查：斜率 3 不是切点的纵坐标，切点必须记为 (1,2)。

  4. 步骤4：用点斜式写切线

    经过 (1,2) 且斜率为 3 的直线，方程是 y−2=3(x−1)。

    y−2=3(x−1)⇔3x−y−1=0

    为什么／检查：验算 3×1−2−1=0 且斜率的确为 3，因此一般式的符号正确。

  5. 步骤5：用凹凸性进行另一种核验

    二阶导数严格小于 0，函数在 x>0 下凹。利用 ln x≤x−1，可直接验证曲线不超过切线。

    y″=−1x2<0

    为什么／检查：对所有 x>0 都有 ln x+2x≤3x−1，等号只在 x=1；切线确实与曲线恰好接触。

05 · 曲线与切线的真实几何关系

06 · 参考答案与独立验算

参考答案：3x−y−1=0。

独立核验：f(1)=ln1+2=2、f′(1)=3；过 (1,2) 斜率 3 的直线正是 y=3x−1。

易错点：忘记 ln x 的定义域、将 3 当成纵坐标、求出 x=1 后直接猜截距，或误写成 3x+y−1=0。

07 · 方法迁移

一般地，对可导曲线 y=f(x)，要求斜率为 k 的切线，应先找所有定义域内满足 f′(x₀)=k 的横坐标，再逐一写 y−f(x₀)=k(x−x₀)。若有多个合法 x₀，就可能有多条平行切线；这和给定一个固定点求切线不同。
