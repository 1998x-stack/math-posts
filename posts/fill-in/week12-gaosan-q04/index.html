填空题 · 第 4 题 · 第 12 周高三数学课堂练习

二项式常数项：从 6−3k=0 找到 60

每选一次 2/x²，总指数就减少 3；仅 k=2 时变量完全抵消。

用户上传试卷照片 · 第 1 张 / 原卷第 1 页 · 年份未注明

01 · 先理解题目在问什么

要求常数项并不是把 x 替换成 1，也不是简单把六次方展开后挑一个数字。六个括号相乘时，每一项来自选择 k 个 2/x² 与 6−k 个 x。关键是数清 x 的正、负指数如何相互抵消，只有指数为零时才真正留下与 x 无关的常数。

研究对象

六次二项展开式

给定条件

x 与 2/x² 分别提供正、负指数

求解目标

找出完全不含 x 的一项

解题路线：设选中第二项 k 次 → 写一般项 → 令 x 指数归零 → 计算组合系数。

02 · 原题（据照片核对）

在 (x+2x2)6 的二项展开式中，常数项为 ______。（x≠0）

03 · 关键观察

一个 x 贡献指数 +1，换成 2/x² 则贡献指数 −2，所以每多选一次第二项，总指数减少 3。六次方展开恰好有 k=0 到 k=6 七种选择次数。

04 · 逐步推导

  1. 数清每一项选择次数。

    设在六个因子中选了 k 个 2/x²，其余 6−k 个位置选 x；k 是从 0 到 6 的整数。

    为什么 / 检查：每个不同位置的选法对应组合数 C₆ᵏ；选取次数不能超过总因子数。

  2. 写出通项并合并同底数幂。

    Tk+1=C6k2kx6−3k

    为什么 / 检查：x 指数是 (6−k)−2k=6−3k；二的系数是 2ᵏ，不得漏掉组合系数。

  3. 令常数项的 x 指数为零。

    6−3k=0⇒k=2

    为什么 / 检查：常数项必须与 x 无关，即 x0=1；k=2 落在 0 到 6 的整数范围内。

  4. 计算该项的数值。

    C62×22=15×4=60

    为什么 / 检查：C₆²=6×5/(2×1)=15，乘上 22=4，因此唯一常数项为 60。

核心公式：把关键关系完整写出来

先明确本题的基本对象 (x+2x2)6；关键转化是 Tk=C(6,k)x(6−k)(2x2)k。

六次二项式展开的原式

(x+2x2)6

展开式的一般项

Tk=C(6,k)x(6−k)(2x2)k

一般项中的 x 指数

x(6−3k)

06 · 答案与核验

最终答案
60

独立验算：k=2 时 x 的指数为 6−3×2=0；相邻 k=1 与 k=3 的指数分别为 +3、−3，都不是常数项。展开式仅此一项满足要求。

易错点：将常数项误解成令 x=1 后的值；或只计算 22=4 而漏掉组合数 C₆²；还需注意原式定义域 x≠0。

07 · 方法迁移

对 (xᵖ+c xᑫ)ⁿ，一般项的指数为 p(n−k)+qk；先求合法的整数 k，再计算系数。
