分式不等式的符号分析：为什么 −2 不能取、0 可以取

先找分子与分母的零点，再按区间判断符号；分母为零的点必须排除，分子为零的点可以纳入。

2023 届上海市虹口区高三一模 · PDF 第 1 页

01 · 先理解题目在问什么

题目给出一个分式，并要求它不大于零。分式的正负同时取决于分子和分母，因此不能只看分子，也不能在没有检查分母的情况下直接交叉相乘。真正需要做的是找到分子为零、分母为零的位置，把数轴分成几个区间，再逐段判断符号。

研究对象

有理式 x/(x+2)

已知条件

分式的值不大于 0，且分母不能为 0

求解目标

写出所有满足条件的实数 x

解题路线：确定定义域 → 找临界点 −2 与 0 → 作符号分析 → 判断端点是否取到。

02 · 原题

不等式 xx+2≤0 的解集为 ______。

03 · 关键观察

关键观察：分式的符号只可能在分子或分母为零处发生改变。这里两个临界点分别是 x=−2（分母为零，不能取）和 x=0（分子为零，可以取）。它们把数轴分成三个符号稳定的区间。

04 · 逐步推导

  1. 先确定定义域。 分母必须非零，所以 x+2≠0，即 x≠−2。

    为什么：当 x=−2 时原分式没有定义，这个点无论符号分析结果如何都不能进入解集。

  2. 找出两个临界点。 分子 x=0 时分式等于 0；分母 x+2=0 时分式无定义。用 −2 和 0 将实数轴分为 (−∞,−2)、(−2,0)、(0,+∞) 三段。

    为什么：在每一段内部，分子和分母都不会经过零点，符号不会改变，因此每段只需任选一个测试值。

  3. 逐段判断分子与分母的符号。 当 x<−2 时，x 与 x+2 都为负，商为正；当 −2<x<0 时，分子负、分母正，商为负；当 x>0 时二者都为正，商为正。

    检查：题目要求“≤0”，所以只保留中间的负值区间，并在分子为零处考虑等号。

  4. 分别处理端点。 x=−2 使分母为零，必须排除；x=0 使原式等于 0，满足不等式，应当包含。

    为什么：有理不等式的端点不能一律开区间或闭区间，必须回到原式逐个代入检查。

06 · 答案与独立核验

答案：(−2, 0]

独立核验：任取 −2 与 0 之间的数，例如 x=−1，分式为 −1；x=0 时分式为 0；x=−2 时分母为 0，因此不属于解集。区间外分式均为正。

易错点：把 x=−2 也写进解集；或忘记不等号含等号而漏掉 x=0。分母为零与分子为零的端点必须区别处理。

07 · 方法迁移

遇到 p(x)q(x) 的不等式时，先列出 p(x)=0 与 q(x)=0 的全部实根，再做符号表。分母零点永远排除；分子零点是否纳入由不等号是否包含等号决定。
