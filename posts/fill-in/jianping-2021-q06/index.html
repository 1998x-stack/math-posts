等比数列前 n 项积：转成离散二次函数

前 n 项积先增后减，n=3 与 n=4 并列最大

2021 建平中学冲刺模拟卷 3 · PDF 第 5、6 页

01 · 先理解题目在问什么

先用前四项的两组和求出公比。

再把前 n 项积写成关于 n 的指数式。

最后利用 n 为正整数，比较二次指数的相邻整数。

解题路线：两组等式相除求公比 → 求首项 → 写出前n项积 → 用离散整数条件确定最大值。

已知a1+a3=10
已知a2+a4=5
目标最大化前 n 项积，n 为正整数

02 · 原题

已知等比数列 {aₙ} 满足 a1+a3=10，a2+a4=5，求前 n 项积 a1a2⋯an 的最大值（n 为正整数）。

03 · 关键观察

两式相除，利用 a2=qa1 与 a4=qa3，得到公比 q=12。

本题的关键：两组等式相除求公比 → 求首项 → 写出前n项积 → 用离散整数条件确定最大值。

04 · 逐步推导

  1. 第 1 步：两式相除，利用 a2=qa1 与 a4=qa3，得到公比 q=12。

    为什么这样做：设公比为 q，则 a3=q2a1、a4=q3a1；第二个已知式正好是第一个已知式乘 q，因此相除可求 q。

  2. 第 2 步：由 a1(1+q2)=10 得 a1=8。

    为什么这样做：由 a1(1+q2)=10 求首项；q=12 后，1+q2=54。

  3. 第 3 步：前 n 项积 Pn=8n12n(n−1)2，指数化简为 −n22+7n2。

    为什么这样做：第k项为812k−1，把前n项相乘时，8要乘n次，公比的指数则相加，形成二次指数。

  4. 第 4 步：顶点在 n=72，故正整数 n=3 或 n=4 时指数为 6，乘积最大 64。

    为什么这样做：指数关于实数n是开口向下的二次函数，顶点在 n=72；n 是正整数，只需比较 n=3 或 4，两者指数都为6。

关键数学关系

q=12,a1=8
Pn=2−12n2+72n
max(Pn)=64

06 · 答案与核验

答案：64

常见误区：n 必须是正整数，不能把连续二次函数顶点 n=72 当作合法答案。
