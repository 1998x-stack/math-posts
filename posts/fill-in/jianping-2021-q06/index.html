等比数列前 n 项积：转成离散二次函数

观察相邻两个前项积的比值，n=3 与 n=4 时恰好并列最大。

2021 建平中学高考冲刺模拟卷 3 · PDF 第 5、6 页

01 · 先理解题目在问什么

题目给出等比数列前四项的两组和，要求前 n 项的乘积何时最大。这里的对象不是前 n 项和，而是把 a₁ 到 aₙ 全部相乘得到 Pₙ。因为 n 是正整数，最后必须做离散比较，不能只把 n 当作连续变量。

研究对象

前 n 项积 Pn=a1a2⋯an

已知条件

a1+a3=10，a2+a4=5

求解目标

找出正整数 n 使 Pₙ 最大

解题路线：用两组和求公比 → 求首项 → 写相邻乘积比 → 按整数 n 判断增减。

02 · 原题

已知等比数列 {aₙ} 满足：

a1+a3=10,a2+a4=5

求前 n 项积 Pn=a1a2⋯an 的最大值（n 为正整数）。

03 · 关键观察

对乘积而言，新增一项会把旧乘积乘上 aₙ₊₁。因此判断 Pₙ 是增是减，不必每次重新算一大串乘积，只要看“下一项”是否大于、等于或小于 1。

04 · 逐步推导

  1. 先求公比。 由于 a2+a4=q(a1+a3)，所以 q=510=12。

    依据：a2=qa1 且 a4=qa3，第二组和正好是第一组和乘以 q。

  2. 求首项。 a1+a3=a1(1+q2)=10，代入 q=1/2 得 a1=8。

    检查：前四项为 8、4、2、1，确实满足两组和分别为 10 与 5。

  3. 用相邻乘积比判断趋势。 Pn+1Pn=an+1=8(1/2)ⁿ=2³⁻ⁿ。

    为什么：Pₙ₊₁=Pₙ·aₙ₊₁；比值大于 1 时乘积增加，等于 1 时不变，小于 1 时减少。

  4. 定位离散最大值。 n=1、2 时比值大于 1；n=3 时比值等于 1；n≥4 时比值小于 1。因此 P3=P4=64，且其余项都更小。

    检查：正整数 n 不能取 3.5；这里是相邻项相等形成的两个并列最大值。

关键数学关系

q=12,a1=8
Pn+1Pn=an+1=8·(12)n
P3=P4=64=Pmax

核心公式：把关键关系完整写出来

先明确本题的基本对象 a1+a3=10；关键转化是 a2+a4=5。

第一组等比数列两项和

a1+a3=10

第二组等比数列两项和

a2+a4=5

由两组和之比求公比

q=12

06 · 答案与核验

答案：最大值为 64，在 n=3 或 n=4 时取得。

**直接计算核验：**前七项积依次为 8、32、64、64、32、8、1；从 n=4 起，新增项小于 1，乘积持续下降。

易错点：不要把通项 aₙ 的变化图当成前项积 Pₙ 的图；本题要比较的是乘积。

07 · 方法迁移

对于任意正项数列，前 n 项积满足 Pn+1Pn=an+1。当新乘数从大于 1 变为小于 1 时，前项积就从递增转为递减；等于 1 时可能出现并列最大。
