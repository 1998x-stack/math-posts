等比数列前 n 项积：转成离散二次函数

等比数列前项积先增后减，整数极值落在 n=3 或 n=4

2021 建平中学冲刺模拟卷 3 · PDF 第 5、6 页

01 · 先理解题目在问什么

题目给出等比数列前四项的两组和，要求前 n 项的乘积何时最大。与求前 n 项和不同，这里每一项都要相乘；利用公比可以把乘积写成指数式，再把指数转化为关于 n 的二次函数。最后还要记住 n 只能取正整数。

解题路线：两组等式相除求公比 → 求首项 → 写出前n项积 → 用离散整数条件确定最大值。

02 · 原题

已知等比数列 {aₙ} 满足 a₁+a₃=10，a₂+a₄=5，求前 n 项积 a₁a₂⋯aₙ 的最大值（n 为正整数）。

03 · 关键观察

两式相除，利用 a₂=qa₁ 与 a₄=qa₃，得到公比 q=5/10=1/2。

本题的关键：两组等式相除求公比 → 求首项 → 写出前n项积 → 用离散整数条件确定最大值。

04 · 逐步推导

  1. 第 1 步：两式相除，利用 a₂=qa₁ 与 a₄=qa₃，得到公比 q=5/10=1/2。

    为什么这样做：设公比为q，则a₃=q²a₁、a₄=q³a₁；第二个已知式正好是第一个已知式乘q，因此相除可求q。

  2. 第 2 步：由 a₁(1+q²)=10 得 a₁=8。

    为什么这样做：由a₁(1+q²)=10求首项；q=1/2后，1+q²=5/4。

  3. 第 3 步：前 n 项积 Pₙ=8ⁿ(1/2)^{n(n−1)/2}，指数化简为 −n²/2+7n/2。

    为什么这样做：第k项为8(1/2)^(k−1)，把前n项相乘时，8要乘n次，公比的指数则相加，形成二次指数。

  4. 第 4 步：顶点在 n=3.5，故正整数 n=3 或 4 时指数为 6，乘积最大 64。

    为什么这样做：指数关于实数n是开口向下的二次函数，顶点在3.5；n是正整数，只需比较3和4，两者指数都为6。

关键数学关系

Pn=2−12n2+72n
max(Pn)=64

06 · 答案与核验

答案：64

常见误区：n 必须是正整数，不能把连续二次函数顶点 n=3.5 当作合法答案。
