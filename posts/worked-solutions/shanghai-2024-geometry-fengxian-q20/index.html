01 · 先理解题目在问什么

这道题先研究椭圆的一条定点弦面积，再证明椭圆的外切线有一个垂直性质，最后同时出现椭圆的弦、双曲线的弦与两个定点 T、N。第三问声称当 ∠ONP=∠ONQ 时，N 的横坐标 n 与两条斜率之和是定值；但原卷明确只排除直线与 x 轴重合，没有排除竖直直线 l₁。取 l₁:x=1 时，两角对所有 n>2 都相等，因此原题字面上存在反例。本篇完整转写原题，给出前两问的证明、第三问反例及可行的附加条件，不把有疑点的命题冒充已证定理。

解题路线：竖直弦面积→椭圆导圆的两切线垂直→原题反例→若附加 l₁ 非竖直则可证明 n=4 与斜率和为0

02 · 原题（按PDF原文转写）

已知曲线 C：x24+y22=1，O 为原点，过点 T=(1,0) 的直线 l₁ 与 C 交于 P、Q 两点。

（1）当 l₁ 与 x 轴垂直时，求 △OPQ 的面积。

（2）过圆 x2+y2=6 上任意一点 M 作直线 MA、MB，分别与曲线 C 切于 A、B，求证 MA⊥MB。

（3）过点 N=(n,0)（n>2）的直线 l₂ 与双曲线 x24−y2=1 交于 R、S 两点（l₁、l₂ 不与 x 轴重合）。记 TR、TS 的斜率为 kTR、kTS。当 ∠ONP=∠ONQ 时，求证 n 与 kTR+kTS 都是定值。

来源声明：上传文件第17页只包含题干和图示，未提供官方答案或解析。以下是独立推导；第（3）问存在可复现的字面反例，因此本文暂设为草稿并明确给出原题与补充条件的区别。

03 · 找到真正的解题关键

第（1）问是一条 x=1 的竖直弦；第（2）问利用椭圆的两条切线斜率方程与外点所在导圆。第三问的逻辑边界尤为重要：l₁=x=1 符合题设“不与 x 轴重合”，但 P、Q 关于 x 轴对称，因此从任何 N=(n,0) 都看见相等的角，n 根本不唯一。

04 · 分步推导与条件校验

  1. 求竖直弦面积

    l₁:x=1 与椭圆 x24+y22=1 联立，得到 y²=3/2，故 P=(1,62)、Q=(1,−62)。弦 PQ 长 √6，原点到直线 x=1 的距离为 1，三角形面积为 √6/2。

    StriangleOPQ=12·6·1=62

    为什么这样做与如何检查：底边取竖直弦 PQ，原点到该直线的水平距离就是高；无需用两点连线求夹角。

  2. 把两条切线斜率写成二次方程

    设外点 M=(u,v)，一条非竖直切线为 y=sx+b。它与椭圆相切当且仅当 b²=4s²+2。因为切线过 M，b=v−su，所以 (u²−4)s²−2uvs+(v²−2)=0。

    (u2-4)s2-2uvs+(v2-2)=0

    为什么这样做与如何检查：相切条件来自将直线代入椭圆并令判别式为零；同一个外点对应的两个实根就是两条切线的斜率。

  3. 使用导圆证明切线垂直

    外点 M 在圆 u²+v²=6 上，因而 v²−2=−(u²−4)。当 u²≠4 时，两斜率乘积 s₁s₂=(v²−2)/(u²−4)=−1，所以两切线垂直；当 u²=4 时，一条切线竖直、另一条水平，结论仍成立。

    s1s2=-1,MA⊥MB

    为什么这样做与如何检查：用斜率乘积 −1 证明垂直时要单独处理竖直切线情形，否则会因分母为零而漏掉导圆上的点。

  4. 构造原题第三问的反例

    取 l₁:x=1。由第一问 P=(1,62)、Q=(1,−62)。对任意 n>2，N=(n,0) 到 P、Q 的连线关于 x 轴对称，而 NO 沿负 x 轴，所以 ∠ONP=∠ONQ 恒成立。特别是 n=3 和 n=5 都符合条件，因此“n 是定值”不成立。

    l1:x=1,n=3或n=5

    为什么这样做与如何检查：这不是对原题进行修改，而是严格保留原题限制后进行逻辑检查；l₁=x=1 不与 x 轴重合，且 P、Q 是两个不同交点，故确属合法构型。

  5. 说明斜率和也不能脱离参数固定

    取一条合法的 l₂：y=(x−n)5，并与双曲线 x24−y2=1 相交于 R、S，可由韦达算得 kTR+kTS=−2k(n−4)/[4k²(n−1)²+3]（其中 k=15）。当 n=3 时为 10/91，当 n=5 时为 −10/139，两者不同。

    n=3:kTR+kTS=1091;n=5:-10139

    为什么这样做与如何检查：直线斜率不是仅凭图中一个角条件就确定的；原题在未排除竖直 l₁ 时，允许多种 n，因此不能得出题目要求的两项全都定值。

  6. 给出加条件后的正确结论

    若额外限定 l₁ 非竖直，可设 l₁:y=t(x−1)，t≠0。将其与椭圆联立，设交点横坐标为 x₁、x₂。两角相等要求 y₁/(n−x₁)=−y₂/(n−x₂)，代入韦达关系约去后得到 n=4。对任意与双曲线有两个不同交点的 l₂:y=k(x−4)，同样用韦达得到 kTR+kTS=0；竖直的 l₂ 则由上下对称直接得到和为 0。

    额外假设 l1 非竖直⇒n=4,kTR+kTS=0

    为什么这样做与如何检查：这是清楚标明的编辑补充条件，不属于原卷原题本身。将竖直 l₁ 排除之后，题目所期待的定值结构才成立。

06 · 答案、独立校验与易错点

原题核查结论：（1）S△OPQ=√6/2；（2）MA⊥MB；（3）原题按字面条件不成立：竖直 l₁=x=1 是反例。若额外要求 l₁ 非竖直，可得 n=4、kTR+kTS=0。

独立校验：反例中 l₁=x=1 确为原题允许的直线；对于任意 n>2，从 N 到上下对称点 P、Q 的角相等。独立代数校验取 l₂ 斜率 1/5，n=3 与 n=5 的斜率和分别为 10/91 与 −10/139，足以否定原题第三问的定值断言。

易错点：不能为求出预期答案而默默排除竖直线：第（1）问明确讨论了竖直 l₁，第（3）问只禁止 l₁ 与 x 轴重合。纠错应保留原题和反例，并把附加条件标为编辑建议。

07 · 方法迁移

几何定值证明前优先验证极端和退化位置。特别是“直线不与 x 轴重合”并不等价于“直线斜率存在且非零”；竖直线是非常重要的合法边界情形。
