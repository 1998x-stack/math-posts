充分条件与必要条件：用解集包含关系判断

x+1/x>2 的解集是 (0,1)∪(1,+∞)，因此它是 x≠1 的充分不必要条件

2023 届上海市崇明区高三一模 · 原题 PDF 第 2 页 · 参考答案 PDF 第 7 页

01 · 先理解题目在问什么

题目比较两个命题：P 是 x+1/x>2，Q 是 x≠1。我们要判断 P 能否推出 Q，以及 Q 能否反过来推出 P。最稳妥的办法不是背“充分、必要”的定义，而是先分别求出两个命题在共同定义域上的解集，再看它们是否包含；若要否定一个方向，只需给出一个合法反例。

第一个条件

命题 P：x+1/x>2

第二个条件

命题 Q：x≠1

判断目标

比较 P⇒Q 与 Q⇒P

解题路线：明确共同定义域 → 解不等式 → 比较解集 → 用反例检查逆命题。

02 · 原题（含全部选项）

设 x∈ℝ，则“x+1x>2”是“x≠1”的（　　）条件。

A. 充分不必要

B. 必要不充分

C. 充要

D. 既不充分也不必要

03 · 关键观察

两个命题必须在同一个讨论范围内比较。由于 1/x 在 x=0 无定义，原式的共同讨论域是 R\{0}。在这个域上，P 的解集只占 Q 的一部分。

04 · 逐步推导

  1. 先确认两个命题共同讨论的定义域。
    D=ℝ∖{0}

    依据与检查：原题写 x∈R，但 1/x 在 x=0 无定义。比较两个条件时，必须在原表达式有意义的共同定义域 D=R\{0} 上进行，不能把 x=0 当作反例。

  2. 把不等式合并成一个分式并因式分解。
    x+1x>2⇔x2−2x+1x>0⇔(x−1)2x>0

    依据与检查：通分时分子 x²−2x+1=(x−1)²。分母 x 的正负决定分式正负，不能直接把 x 约掉。

  3. 解出命题 P 的全部取值。
    P:(x−1)2x>0⇔x∈(0,1)∪(1,+∞)

    依据与检查：当 x<0 时，分子非负而分母为负，商不可能大于零；当 x>0 时，除 x=1 令分子为零外，商均为正。

  4. 写出命题 Q 在同一域上的解集。
    Q:x≠1,x∈D⇒Q的解集为(−∞,0)∪(0,1)∪(1,+∞)

    依据与检查：Q 只要求 x≠1；但原式共同定义域已经排除了 x=0，所以 Q 的实际讨论集合是 R 去掉 0 和 1。

  5. 比较两个解集，并用反例否定逆推。
    P的解集⊊Q的解集;x=−1⇒Q真而P假

    依据与检查：P 的解集是 Q 的真子集，因此 P⇒Q，P 是 Q 的充分条件；取 x=−1，Q 成立而 P 不成立，说明 Q⇒P 不成立，所以 P 不是 Q 的必要条件。

06 · 答案与独立核验

原卷第 7 页参考答案：A（充分不必要）。

独立核验：P 的解集 (0,1)∪(1,+∞) 真包含于 Q 的解集 (−∞,0)∪(0,1)∪(1,+∞)，所以 P⇒Q；x=−1 使 Q 真而 P 假，逆推不成立。

易错点：不要忘记 x=0 不在原式定义域。用 x=0 作反例是不合法的；应使用 x=−1 这样的合法值。

原卷只列标准选项，没有提供逐步解析；本文解集比较和反例为独立教学补充。

07 · 方法迁移

判断“P 是 Q 的什么条件”，始终按两个方向检查：P⇒Q 是充分性，Q⇒P 是必要性。解集语言下，充分性对应 P 的解集包含于 Q；要证明不必要，给出 Q 真而 P 假的合法反例即可。
