线面平行判定：四个说法中为什么只有 D 正确

区分线面垂直、线面角相等，以及两条直线各自平行于同一平面的含义。

上海市杨浦区 2023 届高三一模数学试卷 · 题干 PDF 第 2 页 · 参考答案 PDF 第 8 页

01 · 先理解题目在问什么

这道空间几何选择题考查直线与平面之间的平行、垂直关系。三个错误选项都把“方向关系”当成了“位置关系”：直线可能仍在平面内，两条线也可能只是与平面有相同倾斜角。D 额外说明 n 在平面外，因此才能由 n 平行于平面内的 m 推出 n 与平面 α 平行。

研究对象

平面 α 与两条直线 m、n

判定重点

线面平行要求直线在平面外且没有公共点

求解目标

逐项判断 A、B、C、D 的真假

解题路线：先写线面平行定义 → A/B/C 分别构造反例 → D 用平面内平行线判定定理证明

02 · 原题

对于平面 α 和两条直线 m、n，下列说法正确的是（　　）

  1. 若 m⊥α，m⊥n，则 n∥α
  2. 若 m、n 与平面 α 所成的角相等，则 m∥n
  3. 若 m∥α，n∥α，则 m∥n
  4. 若 m⊂α，m∥n，n 在平面 α 外，则 n∥α

03 · 关键观察与方法选择

先不要急着找一个“看起来正确”的图形。空间关系必须拆成两个问题：两条线的方向是否平行？直线是否与平面相交或包含在平面内？只有把这两件事同时检查，才能避免把“平行于平面”误说成“落在平面里”。

判定定理：平面外的一条直线，若平行于该平面内的一条直线，则它平行于这个平面。

04 · 逐步推导

  1. 先明确线面平行的含义。

    直线与平面平行，要求直线不在平面内，并且与该平面没有公共点。仅仅“方向与平面相容”还不够。

    为什么这样做：本题三个错误选项都利用了“方向关系”偷换“位置关系”；判断时必须同时看方向和交点。

  2. A 不成立：n 可以恰好落在平面 α 内。

    取平面 α 为 z=0，令 m 为过原点的法向直线，令 n 为平面内过原点的一条直线。此时 m⊥α 且 m⊥n，但 n⊂α，并不与 α 平行。

    m⊥α,m⊥n,n⊂α

    为什么这样做：m 垂直于平面，就垂直于平面内经过垂足的任意直线；题干却没有排除 n 本身就在 α 内。

  3. B 不成立：与平面所成角相等，不代表两条直线平行。

    例如平面取 z=0，方向向量分别为 (1,0,1) 与 (0,1,1)。两条直线与平面的夹角都为 45°，但方向不同，不平行。

    u=(1,0,1),v=(0,1,1)

    为什么这样做：线面角只描述方向相对平面的倾斜程度，不记录水平投影朝向；相同倾斜角可以对应很多不同方向。

  4. C 不成立：两条直线都平行于同一平面，彼此仍可能相交或异面。

    例如在平面 z=0 上方的平面 z=1 内，取两条都经过 (0,0,1) 的直线：m 沿 x 轴方向，n 沿 y 轴方向。它们都不与 z=0 相交，却在 (0,0,1) 相交，因此不平行。

    u=(1,0,0),v=(0,1,0)

    为什么这样做：“都平行于 α”只约束每条线相对 α 的位置，不会把两条线的方向锁定成同一个方向。

  5. D 成立：反设 n 与 α 相交，就会推出 n 落在 α 内。

    已知 m⊂α 且 n∥m。若 n 与 α 交于点 P，那么过 P 且平行于 m 的直线必在平面 α 内；但这条直线就是 n，于是 n⊂α，与“n 在平面 α 外”矛盾。因此 n 与 α 无公共点，故 n∥α。

    m⊂α,n∥m,n⊄α⇒n∩α=∅⇒n∥α

    为什么这样做：这是线面平行的判定定理：平面外的一条直线平行于平面内的一条直线，则该直线平行于这个平面。

05 · 把本题的数学结构画出来

空间图采用透视投影，只用于识别线与平面的位置关系；B、C 的反例由正文给出的方向向量精确描述，不能把二维投影中的视觉角度当作空间证明。

06 · 答案与独立核验

原卷参考答案：D。

本站独立核验：A 可取 α:z=0、m 为 z 轴、n 为平面内过原点的 x 轴；B 可取方向向量 (1,0,1) 与 (0,1,1)，它们与 z=0 平面都成 45° 但不平行；C 可取平面外分别沿 x、y 方向的两条直线；D 由线面平行判定定理成立。

易错点与边界：A 选项没有排除 n⊂α；B 中“与平面所成角相等”不锁定水平方向；C 中两条直线分别平行同一平面，不代表它们彼此平行。

07 · 方法迁移

判断空间线面关系时，优先使用“平面内有一条直线与已知直线平行”这一判定定理；同时检查直线是否在平面外。遇到错误命题，先尝试让直线通过垂足或让两条线取不同水平投影方向。
