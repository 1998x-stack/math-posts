## 视觉结构变化

每篇样板统一增加：
1. **题意总览图**：在正式题干前说明研究对象，标出主要对象、已知条件和目标
2. **条件 chips**：把关键数字、区间和目标从长句中提取出来
3. **步骤级 SVG**：放在对应推导步骤之后，而不是集中放在文末
4. **结论图**：突出最值点、可达范围、根数或几何关系
5. **行内 MathML**：原题、步骤标题、关键观察、推导解释和答案中的实质公式都渲染

## 关键图形核验

- **Q04**：图示把单位正方形中心作为最小距离点，四个角作为最远点；对应点积范围闭区间，边界可取到。
- **Q06**：使用离散点强调 n 只能取正整数；连续顶点位于 3.5，真正并列最大出现在相邻整数 3 和 4。
- **Q17**：修正投影示意，明确 D 不必落在三角形 ABC 内；在底面图中区分直角三角形 ADB、等边三角形 ABC 和 DB 与 AC 的平行关系。步骤图再分别说明线面平行和正交坐标。
- **Q19**：明确 x=80 的分段边界；两段各自求最大值后再比较，避免把第一段局部顶点误认为全局最优。
- **Q20**：割线示意采用同一条直线上的 C、D 与中点 M；轨迹图同时画出完整二次曲线和满足参数范围的两支可达弧段，避免把整条曲线误当成轨迹。
- **Q21**：帐篷函数与复合折线均覆盖全体实数；根数图显示 m<0 的两侧射线交点、m=0 的三个根、0<m<2 的四个根、m=2 的两个峰顶和 m>2 的无解情形。二周期图明确区分两个互相映射的不同点与不动点。

## 公式与工程质量门槛

新增 Visual-first 校验：
- overview 必须有 problem visual；
- solution 至少有两个 step visual；
- answer 必须有 conclusion visual；
- 至少 4 张有标题、描述和图注的独立 figure；
- 至少 8 个带可访问名称的行内 MathML；
- 检查 MathML 的 mfrac、msup、msub 等节点子元素数量；
- 从可见 HTML 文本中扫描裸公式残留；
- 样板页段落超过 110 字符时要求拆分；
- Chromium 检查 MathML 实际可见尺寸、图解分布和四种屏幕宽度下的横向溢出。
