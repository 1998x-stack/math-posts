# Three.js 立体数学场景标准

## 适用判断

默认先做二维 SVG。只有三维坐标、空间投影、异面直线、二面角、空间动点或球面结构确实需要旋转观察时才采用 Three.js。简单的球体体积/表面积代公式不需要 3D；一张有半径标记的球体剖面 SVG 更清楚。纯函数、数列、组合、平面解析几何默认 SVG。

## 控件与数学变量一一对应

- 每个滑块必须控制题目中的真实参数（如动点坐标、角度、半径或截面位置），并显示当前数值与相应公式结果。
- 不允许在静态题目上添加无关的 x/y 滑块，不允许只改变球面上的装饰点却声称演示了体积或表面积。
- 模型、公式、文本读数必须由同一份状态计算；不要在 SVG、Three.js 和正文中分别手写近似数据。
- 若唯一任务是观察三维形状，提供旋转、缩放、重置即可，不必制造没有题意依据的数学参数。
- 若控件没有验证具体结论，删除控件，保留静态 SVG。

## 渲染

- 运行依赖锁定 `three@0.160.0`。CDN 加载需要互联网，必须保留静态 SVG 与完整教学文字，明确说明不是全离线部署。
- 使用 `THREE.BufferGeometry`、`LineSegments`、`Mesh`、`WebGLRenderer`；数学坐标不能与屏幕像素坐标混用。
- 统一标注X/Y/Z轴与命名点；区分底面、侧棱、投影、辅助线、动点与法向量。
- 不默认持续旋转；限制像素比，监听尺寸变化，尊重 `prefers-reduced-motion`。
- Canvas 支持鼠标、触摸和键盘旋转/缩放；按钮有可访问名称与可见焦点。
- WebGL 或网络失败时，静态 SVG、公式与文字必须仍完整可见。

## 当前基准场景

- **Q04 正方体动点**：底面点 (P=(x,y,0))，(x,y\in[0,1])，(PA\cdot PC=(x-1/2)^2+(y-1/2)^2+1/2)。滑块控制真实的x、y，读数实时显示点积；中心为1/2，四角为1。
- **Q13 异面直线等距轨迹**：平面点P的坐标控制与两条直线距离的比较；空间直线到平面的高度h必须保留，不能只画投影距离。
- **Q17 三棱锥与二面角**：采用 (D=(0,0,0))、(A=(-\sqrt3,0,0))、(B=(0,1,0))、(C=(-\sqrt3,2,0))、(P=(0,0,1))，展示底面、侧面、投影线和二面角。这里无需伪造x/y参数滑块，旋转/缩放模型即可。
